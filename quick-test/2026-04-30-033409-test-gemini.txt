⏺ 基于我的分析，西柚找词节点失败的原因如下：

  🔍 问题分析

  1. 网站访问正常

  - 西柚找词网站本身可以正常访问 (HTTP/2 200)
  - curl 测试显示网站响应正常

  2. Playwright 超时问题

  - 错误信息：page.goto: Timeout 30000ms exceeded
  - 发生在等待 "networkidle" 状态时

  3. 根本原因

  这是一个现代单页应用（SPA），加载特性导致超时：

  1. 大量外部资源加载：
    - 阿里云验证码组件
    - CDN 资源
    - 多个预加载字体和脚本
  2. 持续的 JavaScript 执行：
    - 微前端架构需要加载多个子应用
    - 实时数据更新可能导致持续网络请求
  3. networkidle 等待策略失效：
    - 某些资源可能持续加载或失败重试
    - 长连接或 WebSocket 连接保持活跃

  4. 前端错误传播

  - 前端界面捕获到 "Failed to fetch" 错误
  - 这是由于 API 请求超时，然后将超时错误作为 "Failed to fetch" 返回给前端

  📊 问题定位总结

  ┌─────────────────┬─────────┬──────────────────────┐
  │      层级       │  状态   │         说明         │
  ├─────────────────┼─────────┼──────────────────────┤
  │ 网站可达性      │ ✅ 正常 │ 西柚找词网站可以访问 │
  ├─────────────────┼─────────┼──────────────────────┤
  │ API 服务器      │ ✅ 正常 │ 端点正确注册并响应   │
  ├─────────────────┼─────────┼──────────────────────┤
  │ Playwright 启动 │ ✅ 正常 │ 浏览器可以启动       │
  ├─────────────────┼─────────┼──────────────────────┤
  │ 页面加载策略    │ ❌ 超时 │ networkidle 等待超时 │
  └─────────────────┴─────────┴──────────────────────┘

  💡 建议的解决方案（不修改代码）

  1. 检查网络连接：确保服务器到 xiyouzhaoci.com 的网络稳定
  2. 增加超时时间：当前是 30 秒，可能需要更长等待时间
  3. 使用不同的等待策略：从 networkidle 改为 domcontentloaded
  4. 添加重试机制：失败后自动重试

  结论：这不是服务配置问题，而是 Playwright 在加载复杂 SPA
  页面时的等待策略问题。网站有大量外部资源和持续的网络活动，导致 networkidle
  策略无法满足。

  function parseCsvLine(line: string): ScrapedKeyword | null {                  
    const fields: string[] = [];                                                
    let current = '';                                                           
    let inQuotes = false;                                                       
                                                                                
    for (let i = 0; i < line.length; i++) {                                     
      const ch = line[i];                                                       
      if (ch === '"') {                                                         
        if (inQuotes && line[i + 1] === '"') {                                  
          current += '"';                                                       
          i++;                                                                  
        } else {                                                                
          inQuotes = !inQuotes;                                                 
        }                                                                       
      } else if (ch === ',' && !inQuotes) {                                     
        fields.push(current.trim());                                            
        current = '';                                                           
      } else {                                                                  
        current += ch;                                                          
      }                                                                         
    }                                                                           
    fields.push(current.trim());                                                
                                                                                
    // Skip if too few fields or no keyword                                     
    if (fields.length < 2 || !fields[1]) return null;                           
                                                                                
    // Extract search volume and trend                                          
    const svParts = (fields[2] || '').split(' ');                               
    const searchVolume = svParts[0] || null;                                    
    const searchVolumeTrend = svParts[1] || null;                               
                                                                                
    return {                                                                    
      rank: parseInt(fields[0], 10) || 0,                                       
      keyword: fields[1],                                                       
      searchVolume,                                                             
      searchVolumeTrend,                                                        
      trafficShare: fields[3] || null,                                          
      rankingPosition: fields[7] || null,                                       
      difficulty: fields[13] || null,                                           
      clickRate: fields[15] || null,                                            
      conversionRate: fields[16] || null,                                       
    };                                                                          
  }                                                                             
                                                                                
  /**                                                                           
   * Extract table data from page

  async function extractTableData(page: Page): Promise<string> {                
    return page.evaluate(() => {                                                
      const rows = document.querySelectorAll(                                   
        'table tbody tr, .el-table__body-wrapper tr, .x-table-body tr',         
      );                                                                        
      if (rows.length === 0) return '';                                         
                                                                                
      const lines: string[] = [];                                               
      for (const row of rows) {                                                 
        const cells = row.querySelectorAll('td, .cell');                        
        if (cells.length === 0) continue;                                       
        const texts = Array.from(cells)                                         
          .map((c) => c.textContent?.trim() ?? '')                              
          .filter(Boolean);                                                     
        if (texts.length > 0) {                                                 
          lines.push(                                                           
            texts.map((t) => `"${t.replace(/"/g, '""')}"`).join(','),           
          );                                                                    
        }                                                                       
      }                                                                         
      return lines.join('\n');                                                  
    });

  🎯 核心问题分析

  waitUntil: 'networkidle' 的问题

  这是导致超时的根本原因：

  1. 西柚找词是 SPA 应用，有以下特点：
    - 持续的后台数据请求
    - WebSocket 连接保持活跃
    - 第三方统计脚本持续运行
    - 阿里云验证码组件加载
  2. networkidle 的严格要求：
    - 需要至少 500ms 内网络连接数 <= 2
    - 对于这种现代 SPA，几乎永远无法满足
    - 导致 30 秒超时

  运行时环境差异

  工作版本：
  - 使用 Bun 运行时
  - 有更优的事件循环处理
  - 浏览器生命周期管理更稳定

  问题版本：
  - 使用 Node.js + tsx
  - 可能在处理长时间等待时有资源清理问题
